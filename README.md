## Entry

I can charge any phone just by touching it, but only if it's already at 100%.

## Why this wins

The brief asks for the most useless superpower: a power so pointless that naming it is the whole joke. This one needs no explanation and no loophole — the power only works in the one situation where it is definitionally unnecessary. It is instantly visual (a hero solemnly touching a full battery), perfectly self-defeating, and fits the one-line, at-most-140-characters format with room to spare. Against any rival power that could accidentally help someone, this one cannot help anyone, ever, by construction.

## Run

```bash
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Writes the entry line (no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, verifies it by reading it back, and prints the line plus its SHA-256.
